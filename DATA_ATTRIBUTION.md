# Data Attribution

This project uses tournament and results data sourced from Liquipedia.

- Liquipedia API Terms of Use: <https://liquipedia.net/api-terms-of-use>
- Liquipedia copyright and content licensing information: <https://liquipedia.net/commons/Liquipedia:Copyrights>

## Attribution

Liquipedia content is licensed under **CC-BY-SA 3.0**. Rankings, exports, and site views produced by this repository should credit **Liquipedia as the source of the underlying tournament data**.

## API use expectations

This repository is intended to comply with the published Liquipedia API terms by:

- using the Liquipedia API rather than scraping generated HTML pages
- caching and re-using fetched API results where practical
- rate-limiting LiquipediaDB API requests to stay within the published limits
- sending a project-specific `User-Agent` with contact information
- keeping API keys private and out of the public repository

## Derived rankings

The rankings shown by this project are **derived outputs** built from curated event histories and local modeling choices. They are not official Liquipedia rankings and should be presented as an independent community project.
