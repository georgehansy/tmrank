Methodology

How tmrank works

tmrank builds rankings from curated Trackmania event placements stored locally after syncing Liquipedia tournament data. The project is intentionally opinionated: event inclusion, profile definitions, weighting, title logic, and GOAT components are all configured locally.

Current ranking

Current ranking is based on conservative rating from the local skill model. Inactive players become more uncertain over time, which lowers their current conservative score until they compete again.

GOAT ranking

GOAT ranking currently combines four components with plain min-max normalization:

  • Prime rating: best rolling prime window average, subject to a minimum active-month threshold.
  • Elite area: accumulated monthly strength above the configured elite threshold.
  • Median conservative: median monthly conservative rating across active months.
  • Title points: major-event placement points using the configured majors list.

Profiles

Profiles are isolated config bundles under config/profiles/<name>/. A profile can override event curation, rating settings, majors, or aliases without changing the default esports profile.
